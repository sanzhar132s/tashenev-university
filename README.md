# Tashenev University

Демонстрационный сайт университета имени Жумабека Ахметулы Ташенева. В проект входят главная страница, история университета, направления обучения, ресурсы для студентов и контакты. Логотип, фотографии и справочные сведения взяты с [официального сайта университета](https://tashenev.edu.kz/ru).

## Локальный запуск

Понадобятся Node.js 24 и pnpm 11.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm build` проверяет типы и собирает сайт в `dist/`. GitHub Actions публикует сборку в GitHub Pages при обновлении ветки `main`.
